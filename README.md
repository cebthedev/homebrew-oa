# homebrew-oa

Homebrew tap for [oa](https://github.com/cebthedev/opencode-agents) — bundle-based skill/MCP loader for OpenCode.

## Install

```bash
brew tap cebthedev/oa
brew install oa
```

Updates:

```bash
brew reinstall cebthedev/oa/oa
```

The formula builds from the `main` branch of the source repo and vendors PyYAML in a private venv.
